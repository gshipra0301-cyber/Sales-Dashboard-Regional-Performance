\# Sales Performance Dashboard



\## Project Overview

This project is a Sales Performance Dashboard built using MySQL and Power BI. The dashboard provides insights into sales, profit, orders, quantity, category, region, segment, and monthly trends.



\## Tools Used

\- MySQL / MariaDB

\- Power BI Desktop

\- SQL

\- CSV Dataset



\## Files

\- orders.csv – Dataset

\- sales queries.sql – SQL queries used for analysis

\- sales performance dashboard.pbix – Power BI Dashboard

\- README.md – Project documentation



\## Dashboard Features

\- Total Sales

\- Total Profit

\- Total Orders

\- Average Quantity

\- Sales by Category

\- Sales by Region

\- Sales by Segment

\- Monthly Sales Trend

\- Profit by Category

\- Interactive Filters (Region \& Category)



\## Steps

1\. Import the dataset into MySQL.

2\. Execute the SQL queries from `sales queries.sql`.

3\. Open `sales performance dashboard.pbix` in Power BI Desktop.

4\. Refresh the data if required.
